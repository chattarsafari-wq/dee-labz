# P14 — Advanced Laboratory Foundation

Added:
- Quality Control definitions with target/lower/upper limits
- QC run recording with automatic PASS/FAIL evaluation
- QC audit/run history
- Sample tracking event timeline
- Barcode-based sample tracking lookup
- Location/status/remarks for sample events
- Inventory lot foundation with expiry and reorder fields
- Lab/tenant isolation on new modules
- Basic QC and sample-tracking UI

Important:
P14 is a foundation release. It does not claim analyzer/LIS device integrations, automated barcode scanner hardware, or full inventory procurement/stock movement workflows as complete.
