# P15 — Operations & Audit

Added:
- Inventory stock movement engine
- Receive/issue/return/waste/adjustment movements
- Balance-after movement ledger
- Insufficient-stock protection
- Expiry monitoring
- Inventory history UI
- Audit log foundation with user, IP, entity and old/new values

Important:
This release does not claim automated supplier purchasing, barcode hardware integration, or accounting reconciliation.


Advanced Analytics is documented in `README_ADVANCED_ANALYTICS.md` and adds revenue, profit/cost, test volume, collection-center, doctor-referral and branch analytics with date-range filtering.
