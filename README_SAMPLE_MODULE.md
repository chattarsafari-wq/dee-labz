# Dee Labz — Sample Collection Module

Workflow:

Booking → Collection Pending → Collected → Received → Testing → Result

Features:
- Sample list with search by barcode/patient
- Status filtering
- Unique barcode/reference generated at booking
- Mark sample collected
- Record collector and collection time
- Receive sample in laboratory
- Reject sample with mandatory reason
- Booking status automatically changes when samples are collected/received
- Tenant isolation through `lab_id`

No extra package is required.
