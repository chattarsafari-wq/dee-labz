DLAB WINDOWS INSTALLATION
=========================

REQUIREMENTS
- Windows 10/11
- XAMPP with PHP 8.2+ and MySQL/MariaDB
- Composer

INSTALL
1. Start Apache and MySQL from XAMPP.
2. Extract this ZIP to a folder such as C:\xampp\htdocs\dlab.
3. Right-click INSTALL_DLAB.bat -> Run as administrator (recommended).
4. Enter the MySQL root password when asked. Press Enter if root has no password.
5. Wait for "INSTALLATION COMPLETE".
6. Run START_DLAB.bat.
7. Open http://127.0.0.1:8000

DATABASE
Name: dlab
Host: 127.0.0.1
Port: 3306
User: root
