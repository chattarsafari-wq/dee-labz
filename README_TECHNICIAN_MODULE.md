# Dee Labz — Technician Worklist Module

Workflow:

Received Sample → Technician Worklist → Enter Results → Save → Complete

Features:
- Technician worklist
- Search by barcode/patient
- Test parameter entry
- Units and reference ranges shown
- Save/update result values
- Records technician and entry time
- Prevents completion while required parameters are missing
- Marks sample completed
- Booking remains in progress until workflow continues
- Tenant isolation through `lab_id`

No extra package required.
