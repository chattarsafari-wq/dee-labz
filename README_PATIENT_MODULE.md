# Dee Labz — Patient Management Module

Features:
- Patient registration
- Auto-generated Patient No
- Name, father/husband name, gender, DOB
- Contact, CNIC, blood group, address, notes
- Patient search
- Patient profile
- Edit patient
- Complete laboratory booking/history view
- Links to available reports
- Tenant isolation via `lab_id`

No extra package required.

Run:

```powershell
composer install
php artisan migrate
php artisan serve
```
